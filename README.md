# java-racingcar-precourse

## 기능 목록

### 1. 자동차 경주 게임
> 주어진 횟수만큼 n대의 자동차가 전진 또는 정지하며 경주를 진행하고, 가장 멀리 이동한 자동차를 우승자로 선정한다.

**경주 규칙**
- 전진 조건: 0~9 사이의 무작위 값이 4 이상일 때
- 각 회차마다 모든 자동차의 이동 여부를 판단하여 실행
- 우승자: 가장 많이 전진한 자동차 (공동 우승 가능)

**자동차 이름 규칙**
- 쉼표(`,`)를 기준으로 구분
- 각 이름은 5자 이하여야 함
- null, 빈 문자열, 공백만으로 구성 불가

**입력 문자열 규칙**
- null, 빈 문자열, 공백만으로 구성 불가
- 쉼표(`,`)만 구분자로 사용 가능 (`;`, `:`, `|`, `/`, `\` 불가)
- 연속된 쉼표 불가 (`pobi,,woni`)
- 쉼표로 시작/종료 불가 (`,pobi` 또는 `pobi,`)

**시도 횟수 규칙**
- 양의 정수만 입력 가능 (1 이상)
- 숫자 형식이어야 함

### 2. 예외 처리
잘못된 값 입력 시 `IllegalArgumentException` 발생 후 애플리케이션 종료

**예외 발생 상황:**
- 자동차 이름이 null, 빈 문자열, 또는 5자 초과인 경우
- 입력 문자열이 규칙을 위반한 경우
- 시도 횟수가 양의 정수가 아니거나 숫자 형식이 아닌 경우
- 자동차 리스트가 null이거나 비어있는 경우

### 3. 우승자 판정
- 단독 우승: 1명의 자동차가 최다 이동
- 공동 우승: 2명 이상이 동일한 최다 이동 거리
- 우승자가 여러 명일 경우 쉼표(`,`)로 구분하여 출력

---

## 입출력

**입력 형식**
```text
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
pobi,woni,jun
시도할 횟수는 몇 회인가요?
5
```

**출력 형식**
```text
실행 결과
pobi : -
woni : 
jun : -

pobi : --
woni : -
jun : --

최종 우승자 : pobi, jun
```
